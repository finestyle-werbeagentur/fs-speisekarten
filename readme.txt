=== Finestyle Speisekarten ===
Version: 1.7.0

So geht's:
1. Plugin hochladen (Plugins > Installieren > Plugin hochladen) und aktivieren.
2. Links im Menü "Speisekarten" > "Neue Speisekarte".
3. PDF hochladen, kurz prüfen, "Veröffentlichen" klicken.
4. Shortcode [speisekarte id="…"] in ein Elementor-Shortcode-Widget kopieren.

Update: Speisekarte öffnen, neue PDF hochladen, "Aktualisieren" klicken. Fertig.

Die PDF liegt unter /wp-content/uploads/speisekarten/<dateiname>.pdf – der Link bleibt immer gleich.
Hinweis: Die PDF muss echten Text enthalten (Export aus InDesign). Gescannte Karten (nur Bild) können nicht ausgelesen werden.
PDF-Auslesen: pdf.js (Mozilla, Apache-2.0 Lizenz).
