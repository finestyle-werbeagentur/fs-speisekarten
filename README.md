# Finestyle Speisekarten

WordPress-Plugin von Finestyle: Speisekarte als PDF hochladen → wird automatisch als sauberes HTML auf der Seite ausgegeben.

## Neue Version veröffentlichen
1. Versionsnummer in `fs-speisekarten.php` an beiden Stellen erhöhen (Kopf `Version:` und `FS_SK_VERSION`), committen, pushen.
2. Auf GitHub unter **Releases → Draft a new release** einen Tag mit derselben Nummer anlegen (z. B. `v1.6.1`), kurz beschreiben, **Publish release**.

GitHub baut dann automatisch `fs-speisekarten.zip` und hängt sie an das Release. Alle Seiten mit dem Plugin zeigen anschließend „Update verfügbar“ – auch in MainWP.
